# CSF.Screenplay.TUnit

**CSF.Screenplay.TUnit** is a [Test Framework Integration] which allows Screenplay-based logic/syntax to be used with tests written in [TUnit].

Learn more at the [Getting Started with TUnit documentation page].

[Test Framework Integration]: https://csf-dev.github.io/CSF.Screenplay/glossary/Integration.html
[TUnit]: https://tunit.dev/
